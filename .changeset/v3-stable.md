First stable `3.0.0`, published under `latest`. The v3 API — a canonical semantic core shared by the TypeORM, Prisma and Drizzle adapters, measured on PostgreSQL, MySQL and SQL Server — replaces the 2.x API; there is no compatibility mode. Read `MIGRATION.md`, "2.x → 3.x", before upgrading, and its "If you already run `3.0.0-alpha.1` or `3.0.0-alpha.2`" table if you ran a prerelease. To stay on the previous major, pin `nestjs-rest-query@^2`.
